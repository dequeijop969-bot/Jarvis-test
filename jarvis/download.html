JARVIS O app
JARVIS para Windows

Tudo pronto. Hora de instalar.

O app traz o Jarvis Code para a sua área de trabalho: ele abre programas, clica, digita, escreve código e entrega no Correio os PDFs e arquivos que cria. É só dizer "Jarvis".

JARVIS Desktop

Windows 10 e 11 JarvisSetup.exe · cerca de 130 MB Node.js 20.6+
Baixar o instalador Não tem o Node.js? Baixe a versão LTS em nodejs.org antes de abrir o app. Prefere sem instalador? Baixe o ZIP.
PASSO 1Abra o JarvisSetup.exe

Clique em Instalar. Se o Windows avisar, use "Mais informações" e "Executar assim mesmo". Não precisa de administrador.

PASSO 2Use o atalho JARVIS

Ele fica na área de trabalho e no menu Iniciar. O Jarvis sobe sozinho, o Jarvis Code aparece na tela e ele pergunta se deve iniciar com o Windows.

PASSO 3Apresente-se

Preencha nome e cidade, cole a chave do Gemini em Ajustes e diga: "Jarvis, abre o Discord e entra na call".

Prefere testar antes?

A versão web roda no Chrome ou no Edge, sem instalar nada. O que precisa do app aparece com cadeado.

Usar no navegador
  • Conversa, slides, clima, agenda, Gmail e imagens
  • Modo Code e Jarvis Code
  • Clicar e digitar nos programas
  • Modo V: diga "Jarvis" em qualquer programa
  • Correio com os PDFs e arquivos que ele cria
