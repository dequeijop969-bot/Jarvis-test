# JARVIS

Assistente pessoal por voz (estilo JARVIS) com app para Windows e o Jarvis Code.

- `jarvis/`: servidor e páginas (site + assistente). No PC: `npm start` ou `mascote\JarvisDesktop.exe`.
- `mascote/`: app para Windows (C#, `build.cmd`).
- `api/` e `vercel.json`: o site público na Vercel (modo site, sem chaves).

Publicar: veja **COMO-PUBLICAR.md**.
